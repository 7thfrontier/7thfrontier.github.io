Palette transparency lets the layer below show through a fractal layer with a transparent background · 2026-10-26

- **Palette transparency lets a lower layer show through a fractal layer with Transparent background.** A palette stop with partial opacity, or an Opacity Field, used to fade the fractal toward the background color while the layer stayed opaque. On a layer with Transparent background on, those parts of the fractal are now see-through by the same amount, so the layer beneath shows through them, on screen and in exports. With the box off, and with a fully opaque palette, nothing changes.
- **Dropping a .flame or .cube file on its drop zone imports it again, and Enter or Space works on four Flame and Post-FX controls.** The Flame import zone and the LUT zone answered a dropped file with a toast saying the file type isn't supported, and Enter or Space did nothing on either zone or on the Post-Affine and Xaos Matrix headers in Flame Studio. Clicking still worked. The app's security policy had always blocked the handlers behind these four controls; they now run from the app's own script.
