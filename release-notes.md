Geometry bookmarks and tours open the way they were saved, and large exports fill in finer detail · 2026-11-16

- **Sharing a single layer that is moved, turned, faded, blended or set on a transparent background now says the link leaves that out.** The link used to open the layer unturned with no notice; it now points you to Save Project, as it already did for two or more layers.
- **An Expedition that moves from a fractal into a geometry pattern now frames the pattern the way switching modes by hand does.** It used to keep the fractal's canvas framing.
- **A bookmark without a saved center or zoom opens again.** An imported or hand-edited geometry bookmark missing one of them failed to open and stayed on the previous view; a missing field now takes its default.
- **A geometry bookmark or share link opened from a fractal view now shows the picture it was saved from.** It used to keep the fractal's canvas framing, so the pattern came out slightly off from the live view.
- **Pattern Rotation and Layer Rotate now turn the same way as View Rotation.** A positive angle on any of the three turns the picture counterclockwise; Pattern Rotation and Layer Rotate used to turn it clockwise, so the same number gave mirror-image turns in one panel. Links, bookmarks, saved states, projects and presets made earlier still show the picture they always did, and the arrow keys and a drag on a pattern still turn it the way they did.
- **Large exports of Indra's Pearls show more of the pattern, not bigger dots.** An export or print drew the same 20,000 points as the on-screen preview, each blown up to the output size, so a 4096 or 8192 export looked coarse and blocky. The point count now grows with the output's pixel area, up to 16 times as many, so the export fills in finer structure and comes out a little denser than the preview, never thinner. A large window or a high-density screen also gets a denser on-screen picture.
- **An export can no longer pick up another layer's settings partway through.** With two or more layers and Live Composite off, a layer preview refreshing while an image export was running could put that layer's settings into the export, so the saved file mixed two layers. Exports now finish before any layer preview refreshes, and if the picture changes during an export anyway, nothing is saved and you are told to try again.
- **Quick SVG export waits its turn.** Starting it while another export or a screen recording was running no longer runs both at once; it refuses, as Print SVG already did.
