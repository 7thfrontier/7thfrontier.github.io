Burning Ship Julia opens on its set · 2026-10-29

- **Burning Ship Julia opens on its set.** It used the Julia set's value of c, at which every point of its starting view escapes within a few steps, so it opened on a dark, nearly empty frame, and its Catalog thumbnail showed the same. It now opens at a c of its own, the Burning Ship's tiny-ship point, which draws a chain of spined ship shapes, and its Catalog thumbnail shows that chain too. The Julia section's Reset returns to that c, and switching to another Julia type gives that type the usual c back. A saved view or share link keeps the c it was made with. A shared Nova link also keeps its own iteration count, which it lost to Nova's default of 64.
- **The Apollonian Gasket's frame is bold again.** The outer circle and the three circles it starts from draw at the full stroke strength. They drew at 40% of it, which a duplicate copy of each one hid until 7.6.1 removed the duplicates, so the frame read dim, most visibly in the Catalog preview.
