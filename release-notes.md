Short-side framing for 3D, and pixel centers · 2026-11-03

- **3D fractals in a portrait frame keep their size and stay in the frame.** The 3D types (Mandelbulb, Mandelbox, Menger, Sierpinski Tetrahedron, Quaternion Julia) sized the picture by the frame's height. In any portrait frame, whether an export, the window itself or a Vertical video with Extend, the subject came out up to 1.8 times larger than in a square export of the same view, and at 9:16 Quaternion Julia and the Sierpinski Tetrahedron ran off both sides. They now size it by the short side, as the 2D families do, on WebGL and WebGPU alike. Square and landscape frames are unchanged.
- **A view no longer shifts half a pixel when it changes renderer, and View Rotation turns about the art center on every path.** The GPU drew each pixel from its center while the CPU, WebGPU (2D and 3D), deep-zoom and CPU export paths drew it from its corner, so the same view sat half a pixel apart between them and a turned view pivoted half a pixel off center away from the GPU. Every path now draws from the pixel center.
- **Test runs no longer leave scratch folders behind in the temp directory.** Four tests created temporary folders on every run and never removed them, and the release script left a small file behind whenever it refused before taking the gate. Together that came to several hundred entries a day on the release machine. The tests now make their scratch through two shared helpers that remove it when the run ends, fails or is stopped, and the release script removes its file on every exit.
