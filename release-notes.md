Nova shows its structure · 2026-10-05

- **Histogram EQ keeps each color's hue.** On a frame where one dark band filled most of the picture, such as the default Julia and Burning Ship views, it spread that band to mid-range and two color channels clipped, so the background turned saturated magenta. On the default Mandelbrot view it did nothing at all. Histogram EQ now limits how far one band can stretch and brightens each pixel without changing its hue, the same on the GPU, CPU, deep-zoom and worker paths.
- **The site no longer ships its source comments.** The landing page's style and script comments, and the service worker's, cited ticket numbers anyone could read with View Source. Assembly and packaging now strip them, and the check reads the served files byte for byte.
- **The Julia pad previews the set you are picking.** The small c-picker in the Inspector drew the plain Julia set for every type, so Burning Ship Julia, Tricorn Julia and Biomorph showed a set other than the one the picked point renders. Each type now previews with its own formula and power. The Julia pad's outer field comes out darker than before: it now counts escape steps the way the main picture does.
- **Wheel, pinch and sliders keep up on 4K views.** On a large GL view, frames drawn while you scroll, pinch or drag a slider render at a reduced scale, and the picture settles to full resolution, identical to a fresh render, when you stop. Copy Image always takes a full frame.
- **Nova shows its structure.** Nova sends almost every point to a root instead of letting it escape, so it was colored as one dark interior with a glow at every catalog view. It is now colored by how many steps a point takes to settle, which shows the boundary between the basins and the bulbs along it. It opens at -0.15 + 0i, zoom 2.2, with 64 iterations; leaving it for another type restores the usual 256. Saved views of Nova change look.
