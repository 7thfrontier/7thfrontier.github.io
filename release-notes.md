A PNG Sequence leaves the inside of the set transparent · 2026-10-31

- **A PNG Sequence leaves the inside of the set transparent when Transparent background is on.** A still PNG with the setting on leaves the inside of the set transparent, but every frame of a PNG Sequence kept it opaque. PNG Sequence frames now leave it transparent too.
