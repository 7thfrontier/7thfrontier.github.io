A startup check catches a graphics card that draws wrong pictures · 2026-11-10

- **A startup check catches a graphics card that draws wrong pictures.** Once the first frame is up, the app draws a tiny test fractal on each graphics path in use and compares it with the same sums done on the CPU. A path that disagrees is switched off for the session: WebGPU gives way to WebGL2, and if WebGL2 itself draws wrong, escape-time fractals render on the CPU. A note says what happened. The check takes about 10 ms, runs entirely on your machine and sends nothing.
