Smooth color climbs to the set · 2026-10-05

- **Smooth coloring now climbs from the palette's first color out to the set (AEON-2013, AEON-1993).** The color spread of every smooth-colored fractal changes. The old curve used up the whole palette in the first few escape steps, so the background filled with rings of every color, then it jumped back to an early color near the set, leaving the palette's last color hard against a dark band. With Repeat above 1 that jump showed as thin black arcs. Now the colors climb smoothly from the first color in the far background to the last color at the edge of the set, with no jump. Ultraviolet on the whole Mandelbrot set shows it most: before, violet and white rings filled the whole frame; now the background is a deep violet that brightens into a glow around the set. The GPU, CPU, deep-zoom and WebGPU paths all match. Collatz opens closer in, where its color spread now shows. Known issue: where the browser refuses a preserved drawing buffer, the first Copy Image after a view change copies the view the app opened with (AEON-2036).
- **The canvas no longer starts as a square (AEON-1934).** Until the first fit ran, the picture's frame used the old square boot layout, so a slow start or a screenshot taken at boot showed one square picture before it widened to fill the window. The frame is full-window from the first paint.
- **Growth patterns show their finished state in thumbnails and layers (AEON-1998).** DLA and the cellular automata that finish in a background worker (elementary CA, Life, Brian's Brain, Day and Night, Gray-Scott) used to be captured from their quick first preview, so a catalog card, a layer thumbnail or a layer in a composite showed partial growth. Those captures now wait for the finished pattern.
- **AEON is credited to 7th Frontier, Inc. alone (AEON-2028, AEON-2029, AEON-2030).** The Foreword now ends with "© 2026 7th Frontier, Inc. All Rights Reserved." The landing page, the catalog poster and the design records credit the company instead of individuals, and a new `lint:attribution` check fails if a personal or AI credit returns. The two home-screen shortcuts say "Open AEON" instead of the old name.
- **The Log Map formula preset draws again (AEON-2025).** It started every point at z = 0, where log is undefined, then settled on one value, so the frame was a single flat color. It now starts at z = c and is colored by the angle of the point it settles on, which shows how that point turns with c and the cut where log jumps.
- **Two catalog entries no longer open nearly blank (AEON-2023).** The Domain-coloring log formula preset painted the whole frame one color, because log(z²+c) settles instead of escaping. It is now colored by the angle of the point it settles on, which shows the branch cut and the bulbs. The Pickover attractor opened as a small speck in the middle of the window; its default view now frames it.
- **Biomorph draws Pickover's creature instead of the Julia set (AEON-2022).** The type iterated z²+c with a square bailout and never applied Pickover's coloring test, so it rendered as the Julia set for the same c. It now iterates z³+c and paints a point as part of the organism when, at escape, its real or imaginary part is still inside the bailout radius, which grows the body's spines. The default bailout is 10, Pickover's own value. Saved views of Biomorph change look.
- AEON-1656 and AEON-1876: the clipboard-copy and export-framing checks frame a content view, boot on a fixed seed, and declare the stale fallback copy against AEON-2036.
- AEON-2008 and AEON-2009: timing tests wait on the app's own signals instead of fixed sleeps.
